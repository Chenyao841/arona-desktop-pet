📖 桌宠操作册

从这里开始

按顺序做完这三步，桌宠就能跑了；之后每个模块想用哪个再单独开

① 起服务 必须

  • 数据库：建库 → 导入结构 → 导入默认内容
    mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS db03 DEFAULT CHARACTER SET utf8mb4;"
    mysql -u root -p db03 < db/schema.sql
    mysql -u root -p db03 < db/seed.sql
  • 数据库账号密码在 src/main/java/com/cy/config/MyBatisConfig.java（默认 root / CHANGE_ME_DB_PASSWORD，改成自己的）
  • 启动后端：zhuochong/一键启动.bat 或 IDEA 里跑 ZhuochongApplication（端口 8080）
  • 启动桌宠外壳：zhuochong-electron 下 npm start（托盘出现图标即可）

② 登录管理页 默认账号

  • 默认账号：老师 / 密码 123456（身份「管理员」，有全部权限）
  • 改法：src/main/resources/application.yml 里的 login.username / login.password / login.name / login.identity
  • identity 只要不是「员工」就有写权限；写「员工」会变成只读账号
  • 登录页：http://localhost:8080/登录.html；管理页：桌宠管理.html

③ 填 AI Key 必须

  • 打开桌宠「基础设置」窗口（托盘右键 → 基础设置）→ 左侧 🧠 AI 设定 → 填 API Key、API 地址（默认 DeepSeek）→ 保存配置
  • 左边「AI 提示词」区可以改人设与功能清单（按版本管理：先「查找」载入，改完「提交」）

不想看长文？记住三句话

  • 所有功能都默认关闭，想用哪个就去「桌宠设置」对应模块页把首行开关打开
  • 开关下面的内容才是该模块的配置项（Key、路径、模型、音质…）
  • 大部分设置改完即自动保存，但前端资源改动要 Ctrl+F5；后端 Java 改动要重启后端

快捷键

  • Ctrl+Shift+Z：锁定/解锁桌宠窗口（锁定时鼠标可穿透到下层窗口，麻将/抽卡时需要）
  • Ctrl+Shift+Q：强制停止麻将自动打牌
  • F12：桌宠开发者工具（看日志很有用）

鼠标点桌面（区域点击穿透）

  • 鼠标移到桌宠身上（模型/对话框/右下角按钮）→ 自动收回点击，桌宠恢复正常交互
  • 鼠标移到桌宠以外的桌面区域 → 不会立刻放手：视线跟随等状态继续保持着，桌宠随时还能点
  • 真的要操作桌面时：在桌宠以外点一下（这一下会被桌宠吃掉、不产生效果），之后的点击就都交给桌面了
  • 鼠标再回到桌宠身上时自动收回点击，如此循环；嫌麻烦可用 Ctrl+Shift+Z 直接锁定/解锁整窗穿透

桌宠设置窗口（基础设置）

托盘右键 →「基础设置」；左侧菜单一页一个模块，每页首行是模块开关

通用规则

  • 每页首行是模块总开关：关掉后该页内容隐藏，相关能力（含指令）失效
  • 改动立即自动保存：前端行为类存浏览器 localStorage，功能类存后端 ai_config
  • 每页底部是该模块的指令表：左边「主指令」是代码内置触发词（不可改），右边别名可增删改，重复会标红

🔊 语音 TTS

需要什么 依赖

  • GPT-SoVITS 整合包（本项目用的是 v2Pro 版），默认起在 http://localhost:9880
  • application.yml 里 tts.python / tts.api-dir 指向整合包路径，tts.auto-start: true 时后端会自己拉起 api.py
  • 语音模型（.ckpt / .pth）与参考音频（wav + 同名 txt）需要自备，放进对应目录后在设置页选

怎么开 步骤

  1. 确认 GPT-SoVITS 在跑：浏览器打开 http://localhost:9880/docs 能看到接口文档
  2. 设置窗口 → 语音 TTS → 顶部开关打开 → 「GPT 模型」「SoVITS 模型」下拉选好 → 点「切换语音模型」
  3. 点「▶ 试听」，能出声即通；不出声看右下角提示与后端控制台

听感不对怎么办 排错

  • 句首语气词被拉长音、吞字（如「哇！老师…」）→ 用「🔬 语音合成调试」页逐个变体试听，选定后设为默认（变体 2「语气词后强停顿改逗号」通常最稳）
  • 换过语音模型后声音怪 → 缓存里还是旧模型的音频：清空 tts_cache 目录后重试
  • 参考音频：建议 5~8 秒、单人、干净；txt 内容必须与音频逐字对应，否则容易拉长音/复读
  • 太慢：单句约 1~3 秒属正常；命中缓存 0.1 秒 内。想更快可在设置页调小「样本步数」（质量会略降）
  • 让常用回复秒出：管理页 →「语音库管理」→ 点预热，会把所有基础回复（登录/点击/摸头/闲置等）提前合成进缓存，之后这些互动几乎零等待
  • 文字已经比语音先出来了：响应一到达就先显示文字+表情，语音随后跟上（所以"感觉慢"通常等的是 LLM 而不是语音）

🧊 Live2D

需要什么 依赖

  • 模型文件：.model3.json + .moc3 + textures/ + 可选 .physics3.json，放在 static/live2d/ 下顶层
  • 本项目不附带模型（版权原因），请自行获取后放进上述目录
  • 表情文件 .exp3.json 放在 static/live2d/expressions/（可选，模型自带的不够用时自己加）

怎么开 步骤

  1. 设置窗口 → Live2D → 顶部开关打开 → 「🔄 重新读取」→ 模型下拉选中你的模型（写入 pet_settings.live2dModel）
  2. 刷新桌面版（Ctrl+F5）→ 模型应加载出来；看控制台日志 [L2D] 就绪 模型尺寸 …
  3. 位置/大小不对：用 🎯 调整模式拖拽与滑块，或在本页填 XY 偏移与缩放

表情映射表 进阶

  • 作用：把「图片表情名」（如 aluona_kaixin.png）映射到 Live2D 表情文件（如 正常微笑，多个用逗号表示叠加）
  • 改法：设置页底部表格直接编辑 → 保存即时生效；重名会标红报错
  • 自制表情：在 static/live2d/expressions/ 建 xxx.exp3.json，格式照抄现有文件（Type + Parameters[{Id,Value,Blend}]），重启桌面版后可被引用
  • 只能用模型已有参数；造不出全新形状（比如爱心瞳孔需要改模型美术）

常见问题

  • 模型不出来：看控制台 [L2D] 日志；确认 model3.json 在 static/live2d/ 顶层、且内含的贴图路径正确
  • 眼睛直勾勾：开启「空闲随机视线」（本页）；它会在空闲时随机看，说话时回到看老师
  • 某个部位不响应：用指令 参数巡览 / 眼球诊断 逐个扫参数，屏上会显示参数名与中文名

🧠 AI 设定

必填 必须

  • API Key：DeepSeek 或兼容接口的密钥；API 地址默认 https://api.deepseek.com/v1/chat/completions
  • 对话模型：deepseek-chat（快）或 deepseek-reasoner（慢但更会推理）

AI 提示词（决定它像不像阿罗娜）

  • 分两块：桌宠设定（system，人设与说话风格）与功能清单（function，告诉它怎么输出 JSON、有哪些能力）
  • 按版本号管理：填版本 → 「🔍 查找」载入 → 改 → 「💾 提交」覆盖该版本；打开页面时默认载入最大版本
  • 改之前建议先「查找」当前版本并备份文本；提示词改坏会直接改变说话方式与 JSON 结构
  • 回复格式约定的要点：boat_text（正文）、motion（表情文件名）、【】=内心OS（会念）、（）=动作（不念）

相关数据在哪

内容位置
长期记忆管理页「桌宠记忆库」（表 pet_memory），会全量注入提示词
最近发生了什么表 event_book（摸头/点击/喂奶/听歌/游戏等），对话时注入最近 5 条
风格语料管理页「风格语料库」（表 style_exemplars），按关键词召回当范例
关键词规则管理页「本地规则库」（表 response_rule），命中关键词就播固定文本+表情+音效
当前时间后端每次响应前注入「北京时间 + 星期 + 时段」，无需配置

🔍 联网查询

需要什么 依赖

  • 博查（Bocha）Web Search 的 API Key —— 在博查 AI 开放平台申请，有免费额度
  • DeepSeek 的 API 不带联网，所以必须外接搜索源；没有 Key 就只能靠模型记忆回答

怎么用 步骤

  1. 设置窗口 → 🔍 联网查询 → 打开模块开关 → 填 API Key → 「💾 保存」
  2. 点「🔍 测试检索」确认能返回结果（失败时会显示原始响应，把它发出来即可定位是 Key 问题还是结构问题）
  3. 桌面版点右侧 🔍 按钮（变蓝）→ 输入问题 → 发送 → 这一次会先联网检索再回答，发完按钮自动熄灭

注意

  • 不会影响日常闲聊：只有你点了 🔍 的那一条消息才联网，其余零延迟零费用
  • 检索结果以「【联网资料（检索于 … 北京时间）】」注入提示词，并要求它只依据资料、没查到就直说
  • 返回条数可调（默认 5）；条数越多越耗 token

📺 直播

需要什么 依赖

  • B站直播间号（room_id）与 B站 Cookie（bili_jct=…; SESSDATA=…，从浏览器登录态里复制）
  • Cookie 用于弹幕长连接鉴权；不填通常连不上或很快断开

怎么开 步骤

  1. 设置窗口 → 直播 → 填房间号与 Cookie → 保存
  2. 顶部「直播模式」开关打开（会写入后端 ai_config.live_mode，桌面版重启后生效）
  3. 「弹幕抓取」开关控制是否接收弹幕；冷却内置 10 秒/条，防刷屏
  4. 也可以用聊天指令 开启直播 / 关闭直播 切换

行为特点

  • 直播模式下提示词会追加直播规则：以 VUP 身份热情回应粉丝，回复更短（1~3 句）
  • 观众指令：排队 / 取消排队 / 下一个 / 排队列表
  • 进入直播间欢迎会自动去重（30 秒内同一人只欢迎一次）

🀄 雀魂麻将

需要什么 依赖

  • 雀魂（麻将）窗口在屏幕上，且桌宠后端能截屏（application.yml 里 spring.main.headless: false）
  • 区域坐标来自「区域标注工具」：按自己的分辨率标注摸牌区、手牌区、按钮等
  • 模拟器/游戏以管理员运行时，普通权限的后端点不动它（UIPI），需要以管理员身份运行后端

怎么用

  • 设置窗口 → 雀魂麻将 → 打开插件开关 → 点「🎯 打开区域标注工具」按自己的界面标注
  • 聊天指令：看看我的牌（读牌+建议）、打把麻将（自动打）、结束麻将、麻将状态、出牌 三条、摸牌 三条、误报 三条、打开合作模式（吃碰杠交给你）
  • 急停：Ctrl+Shift+Q

🎮 网络天才

玩法

  • 聊天说 网络天才 开始；可选难度与出题方向（你出题它猜 / 它出题你猜）
  • 「游戏快捷选项」打开后，它提问时对话框上方会出现「是 / 可能是 / 可能不是 / 不是」按钮，点一下即回答
  • 游戏模型可单独选（推理模型更会猜，但更慢）
  • 结束：说 不玩了 / 结束游戏；也可以点管理页「历史对话管理」清掉残留

🎵 网易云听歌

需要什么 依赖

  • 本机跑 NeteaseCloudMusicApi（默认 http://localhost:3000），application.yml 里 netease.app 指向其 app.js，auto-start: true 时后端自动拉起
  • 想用「播放收藏歌单」需要填网易云 UID（设置页 → 网易云听歌）

常用指令

  • 放歌：播放音乐（随机推荐队列）、点歌 反方向的钟、网易云 反方向的钟（先给候选列表）
  • 控制：暂停 / 继续 / 下一首 / 随机播放 / 单曲循环 / 音量加大 / 静音
  • 查看：当前播放、歌曲队列（★ = 自己点的歌，会自动优先播）
  • 本地音乐文件播放已移除，全部走在线接口

👁 桌面视觉

能力

  • 看到你的屏幕并据此回应（点 👁 一次 → 下一条消息带截图）
  • 允许 AI 操控鼠标完成界面操作（点 🖱️ 一次 → 下一条消息）
  • 蔚蓝档案自动抽卡：说 帮老师抽个卡，按标注的区域做图像匹配与点击

注意 权限

  • 截屏用 java.awt.Robot，所以后端必须非 headless（application.yml 已设 headless: false）
  • 合成鼠标点击受 UIPI 限制：目标程序若以管理员运行，请以管理员身份运行后端与 IDEA
  • 截图会存到 desktop_vision_log/（用于排查）；不想留可在设置页看到目录后自行清理
  • 抽卡的匹配阈值、点击间隔、黑屏等待都写在 GachaService.java 顶部常量里，改完需重启后端

  • 「桌宠基础设置」已搬到桌宠设置窗口的 🧠 AI 设定页，管理页不再提供

常见问题 / 排错

能跑起来但不说话 / 不回应

  • 看桌面版 F12 控制台与后端控制台：/talk 是否 200、有没有 API Key 报错
  • API Key 没填或额度用尽 → AI 设定页检查；deepseek-reasoner 会明显更慢，可临时换 deepseek-chat

改了东西没生效

改了什么怎么生效
前端页面/JS/桥接（static/**）同步到 target/classes/static 后 Ctrl+F5；改桥接要同时把引用版本号 ?v=N 加一
后端 Java重新编译并重启后端
Electron main.js / preload.js重启 Electron
CSSCtrl+F5；仍不生效看 <link> 是否带版本号

响应慢 / 语音卡

  • 单句语音正常 1~3 秒；命中缓存 0.1 秒 内
  • GPT-SoVITS 是否在跑、是否用了 GPU；枪占 GPU 的程序（游戏/麻将自动化）会让语音明显变慢
  • 「样本步数」调小可提速（音质略降）；参考音频建议裁到 5~8 秒
