## 三、怎么挑图（运行逻辑）

**发放条件（P4 收紧后）**：一条回复要同时过三道闸门才会配表情图

1. **情绪变化较大**：AI 给的 `emotion` 落在强情绪集合里
   （默认 `激动/害羞/生气/慌张/难过/开心/震惊/俏皮`，配置项 `qq.emoji-strong-emotions`）；
   没给 emotion 时看文本强信号：连续两个以上感叹号、或出现「哈哈/嘿嘿/呜呜/哇/啊啊/讨厌/太好了…」；
   `认真/怀疑/困惑/无语/温柔/平静` 这类平淡情绪**一律不发**。
2. **间隔冷却**：同一个群里，中间至少隔 `qq.emoji-min-gap` 条纯文字回复（默认 **5** 条）才允许再发一张；
   发出去后计数清零。（从没发过图的群不受这条限制，开机第一句强情绪也能配图）
3. **可选随机抑制**：`qq.emoji-probability`（默认 100 = 不抑制）

过了闸门之后，从该情绪对应的候选里随机挑一张，且避免连续两次用同一张。

运行时可用管理员指令调：`/emoji`（概况）、`/emoji gap 5`、`/emoji on|off`。

## 四、自检

```bash
GET  /qq/status          # emojiEnabled / emojiCount / emojiSent
GET  /qq/emoji           # 完整标注表（文件名 → 表情内容），核对用
POST /qq/emoji/test?group=<群号>&file=32.png   # 往群里发指定表情试效果
```
