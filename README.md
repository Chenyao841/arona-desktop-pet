# 桌面桌宠（Arona Desktop Pet）

一个跑在自己电脑上的 **Live2D 桌宠**：能对话、能出声、能陪你玩游戏，也能帮你盯直播间和麻将牌桌。
纯本地运行，不上传任何数据到作者的服务器。

> **本仓库用途**：技术展示与作品留档（面试/简历可查）。**体验包请向作者索取**，勿自行分发。
> 详细开发文档见 [`zhuochong/PROJECT_OVERVIEW.MD`](zhuochong/PROJECT_OVERVIEW.MD)（含 31 条踩坑手册与完整更新日志）。

## 它能做什么

| 模块 | 说明 |
|---|---|
| 💬 对话 | 接入大模型（DeepSeek），带人设、长期记忆（`pet_memory`）、事件簿（"最近发生的事"）、风格语料 |
| 🗣 语音 | 本地 GPT-SoVITS 合成，参考音频可选/可试听；逐句边说边出、断点续播；句级表情联动 |
| 🎭 表现 | Live2D 模型 + 17 套表情；「模型规则库」按**情境**配表情/动作/音效；情绪分类、闲置小动作 |
| 🎵 音乐 | 网易云搜索点歌 / 收藏歌单 / 推荐队列；**独立蓝白操控器面板**（上一首历史回退、插播不打乱队列、进度拖动、音量） |
| 🀄 麻将 | 雀魂看牌/出牌建议（视觉识别 + 模板比对 + 参考牌面比对）、合作模式 |
| 🎮 游戏 | 网络天才猜物；**你画我猜**（老师画板作画 → 阿罗娜看图猜，带"改了哪里"的对比记忆，游戏不进长期记忆） |
| 🎬 陪玩点评 | 看屏幕说短评（画面变化阈值 + 语境识别） |
| 🖥 壳/交互 | Electron 无边框透明置顶窗口、区域点击穿透、窗口位置记忆、多窗口（设置/画板/播放器） |

## 技术栈

- **后端**：Java 17 + Spring Boot 3（jakarta）· MyBatis 注解 Mapper · MySQL 8 · JWT 拦截器
- **前端**：原生 HTML/CSS/JS + axios · Live2D Cubism SDK 5 · Canvas 绘图工具
- **桌面壳**：Electron 33（frame:false + transparent + alwaysOnTop）· preload + contextBridge IPC
- **AI/语音**：DeepSeek Chat / 视觉模型 · 本地 GPT-SoVITS（9880）· 网易云音乐 API（本地 Node 服务）

## 目录结构

```
zhuochong/                 Spring Boot 后端 + 前端页面（static/）
  ├─ src/main/java/com/cy/ 控制器 / 服务 / Mapper / 三段式模块
  ├─ src/main/resources/static/  桌宠桌面版.html、桌宠设置.html、你画我猜.html、音乐播放器.html …
  ├─ db/                   schema.sql + seed.sql（脱敏种子数据）
  └─ PROJECT_OVERVIEW.MD   设计决策、坑点手册、更新日志
zhuochong-electron/        Electron 壳（main.js / preload.js / 启动脚本）
图标/                       图标源文件与生成脚本
```

## 自己跑起来（开发向）

1. 装 MySQL 8，建库 `db03`，导入 `zhuochong/db/schema.sql` 与 `db/seed.sql`
2. 改 `zhuochong/src/main/resources/application.yml` 的数据库连接与本机路径
3. 在「基础设置 → AI 设定」里填**你自己的** API Key；TTS 相关路径指向你自己的 GPT-SoVITS
4. `zhuochong/一键启动.bat` 起后端，`zhuochong-electron/启动桌宠.vbs` 起桌宠
